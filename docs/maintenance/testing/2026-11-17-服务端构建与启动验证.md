## 日常启动

在仓库根目录执行：

```bash
cd src/server
make gdb_test
python3 database/run_local.py
```

`make` 只编译；`is up to date` 表示无需重新编译。Python 脚本加载本地数据库配置并启动服务。运行时终端持续等待属于正常状态，按 Ctrl+C 停止。已有服务占用 8081 时不要重复启动。
