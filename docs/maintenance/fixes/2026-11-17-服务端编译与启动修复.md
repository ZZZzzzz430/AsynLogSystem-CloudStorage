# 2026-11-17：服务端编译与启动修复

## 故障与原因

- `make gdb_test` 编译失败：SessionRepository.cpp 残留 Git 合并冲突标记，两个分支内容未正确整合。
- `undefined reference`：完整 insert 实现之外，认证调用需要的 create、find、revoke 也必须保留。
- `Invalid or missing configuration: STORAGE_DB_NAME`：直接执行程序时未加载数据库环境变量。
- `HTTP service failed`：先前验证遗留的 gdb_test 占用 8081 端口；错误日志又触发对 8080 日志备份服务的连接重试。

## 修改与处理

- 整合 SessionRepository 实现，补充 Statement.hpp，保留 insert 和认证所需方法。
- run_local.py 无参数时切换至 src/server 并加载本地 runtime.json，执行 ./gdb_test。
- 本地数据库配置保存于被 Git 忽略的 build/local-auth/runtime.json；不在文档中记录密码。
- 停止遗留验证进程，在 HTTP 绑定失败处补充端口和系统错误提示。
